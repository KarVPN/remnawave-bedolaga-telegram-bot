# 5.0.0-karvpn.1

Основа: Bedolaga 5.0.0. Ниже перечислены доработки форка KarVPN;
история изменений исходного Bedolaga в этот список не включается.

- Сборка и проверка Docker-образа `linux/amd64` на GitHub с публикацией в приватный GHCR.
- Доставка образа через Ansible с проверкой параметров и закреплением digest вместо сборки на VPS.
- Перенос действующего профиля Telegram Mini App из серверных патчей в сборку образа.
- Доработки кабинета KarVPN: интеграция BFF и идентификация пользователей.
- Массовые действия над подписками, журнал операций, фильтры и уведомления о результатах.
- Отдельная нумерация релизов KarVPN и короткие release notes без повторного включения истории upstream.

Существующие PostgreSQL, Redis и volumes при доставке образа сохраняются;
этот релиз не выполняет миграцию PostgreSQL на VPS.
